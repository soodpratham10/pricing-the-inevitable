# Annuity-certain values

Annuity-certain values

## Usage

``` r
annuity_certain(n, i, due = TRUE)
```

## Arguments

- n:

  Number of payments (vector allowed).

- i:

  Effective annual interest rate.

- due:

  TRUE for payments at the start of each year, FALSE for the end.

## Value

The present value of n payments of 1.
