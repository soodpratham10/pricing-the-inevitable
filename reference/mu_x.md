# Force of mortality

Force of mortality

## Usage

``` r
mu_x(m, x)
```

## Arguments

- m:

  A mortality object from
  [`mortality_law()`](https://soodpratham10.github.io/pricing-the-inevitable/reference/mortality_law.md).

- x:

  Age or vector of ages.

## Value

The force of mortality at each age.
