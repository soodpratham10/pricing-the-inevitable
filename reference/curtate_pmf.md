# Probability function of the curtate future lifetime

Probability function of the curtate future lifetime

## Usage

``` r
curtate_pmf(q)
```

## Arguments

- q:

  Annual death probabilities from
  [`q_path()`](https://soodpratham10.github.io/pricing-the-inevitable/reference/q_path.md).

## Value

P(K = k) for k = 0, 1, ..., length(q) - 1.
